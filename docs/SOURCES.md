# Sources

Every external source IDEA Keystage relies on, grouped by publisher. All were read on 2026-10-01 unless a line says otherwise. Facts taken from them, with quotes, are in `docs/DECISIONS.md`.

## SolidWorks (Dassault Systemes)

The SolidWorks profile is built only from Dassault's SOLIDWORKS help at help.solidworks.com, for versions 2025 and 2026. Nothing in it is written from memory.

- **294 help pages**, listed one by one with URL, title, version and date read in the `sources` array of `data/profiles/solidworks.json`: 139 for 2025 and 155 for 2026. 284 are in the core SOLIDWORKS help (`/english/SolidWorks/sldworks/...`), 9 in the 2026 online tutorials (`/english/swtutorialonline/...`), and 1 is the 2025 What's New topic "Search Commands (2025 SP2)" (https://help.solidworks.com/2025/english/WhatsNew/c_ui_search_commands.htm), whose screenshot (https://help.solidworks.com/2025/english/WhatsNew/krt1738080155112.image, SHA-256 `150a8aed109ea30d5984964e9f2b10aef80bbc254fa5ce97df94556a5b9835c8`) is the source of the eight 2025 standard view entries marked `"evidence": "screenshot"`.
- Every shortcut and mouse entry names its sources by id and carries a verbatim quote from the page (or, for the eight screenshot entries, the label read from the image).
- The second search for gaps pattern-searched 15,452 page texts (every table-of-contents topic in both versions, the What's New sets, the 2026 tutorials, the API help and 288 site searches). The 2026 What's New PDF (https://files.solidworks.com/Supportfiles/Whats_new/2026/English/whatsnew.pdf) was read and had nothing to add; the 2025 PDF could not be fetched.
- Pages used for the import decision (DECISIONS item 4), each in its 2025 and 2026 form: the SOLIDWORKS Settings Wizard (https://help.solidworks.com/2025/english/SolidWorks/sldworks/c_solidworks_settings_wizard.htm), the Installation guide's Settings Wizard topic (https://help.solidworks.com/2025/english/Installation/install_guide/t_settings_options_welcome.htm), the API's `ISldWorks::SaveSettings` (https://help.solidworks.com/2025/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.ISldWorks~SaveSettings.html), Customize Keyboard (https://help.solidworks.com/2025/english/SolidWorks/sldworks/HIDD_CUSTOMIZE_KEYBOARD.htm), Keyboard Shortcuts (https://help.solidworks.com/2025/english/SolidWorks/sldworks/r_keyboard_shortcuts.htm), and, for the rename, the 2022 Copy Settings Wizard page (https://help.solidworks.com/2022/english/SolidWorks/sldworks/c_copy_settings_wizard.htm) and the 2023 page (https://help.solidworks.com/2023/english/SolidWorks/sldworks/c_solidworks_settings_wizard.htm).

The name "SolidWorks" appears in this app only as plain text naming the profile. No SolidWorks or Dassault logo or artwork is used.

| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| `src/lib/classroom/plate.css`                  | The shape language ("raised means pressable, inset means status"), one geometry with per-theme color blocks, the composite edge, recessed chip, raised panel, well, housing, display screen, LED lamp, the lit key's broken ring, the etched divider, the `superellipse(0.25)` chamfer, the shape tokens, and the IDEA and Space White color blocks | `src/lib/styles/plate.css`; the overlay construction in `src/lib/renderer/callouts.css` |
| `src/lib/classroom/plate.ts`                   | One class that turns the language on                                                                                                                                                                                                                                                                                                                | `.ks-plate`                                                                             |
| `src/lib/design-system/colors.css`             | The IDEA palette, the classroom register and the role layer                                                                                                                                                                                                                                                                                         | `src/lib/styles/tokens.css`                                                             |
| `src/lib/design-system/typography.css`         | Rajdhani, Share Tech Mono and Orbitron roles, weights, type scale, tracking                                                                                                                                                                                                                                                                         | `src/lib/styles/tokens.css` (the Chakra Petch face was left out: not bundled)           |
| `src/lib/design-system/effects.css`            | Glows, bevels, elevations, radii, spacing                                                                                                                                                                                                                                                                                                           | `src/lib/styles/tokens.css` (the blueprint grid backdrop was left out: no grids)        |
| `src/lib/design-system/motion.css`             | Every animation gated on `prefers-reduced-motion: no-preference`                                                                                                                                                                                                                                                                                    | every animation in the overlay and settings CSS                                         |

## Audio

Every key sound in IDEA Keystage is original. The 12 sound packs are synthesized at run time in `crates/keystage-core/src/synth.rs` from filtered noise and damped resonant modes (48 kHz, under 120 ms per sound). No recording, sample or sound file from any other product or library is used, and nothing from Keystro.

## Icons and images

The app icon and the tray glyphs are drawn by this project (`assets/icon`, `src-tauri/icons`, `src-tauri/src/app/icons.rs`). The overlay is SVG, CSS and canvas only, with no raster art. The two screenshots in `docs/images/` were captured from this app's own overlay by `scripts/screenshots.mjs`.
