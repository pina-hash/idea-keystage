# Parity with Keystro

One line per Keystro feature confirmed in Phase 1 research (Keystro's home page https://keystro.app/ and its Microsoft Store listing https://apps.microsoft.com/detail/9n9p8jlx5kmq, both read 2026-10-01). Each is marked **built** or **not built**, checked against the code in this repository. IDEA Keystage uses no Keystro name, asset, theme or sound; parity means a comparable feature, built from scratch.

| #   | Keystro feature (source id from the Phase 1 parity research; A = the seven requested claims, B = other statements on keystro.app or the Store listing) | Status                         | How, or why not                                                                                                                                                                                                                                                      |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Floating keystroke widget placeable at any pixel (A1)                                                                                                  | Built                          | Callouts sit at one of nine anchors with pixel offsets (settings, or `anchor`, `x`, `y` in an OBS source URL), on the native overlay or in OBS. No drag-to-move; placement is by numbers.                                                                            |
| 2   | Pick which connected screen shows keystrokes (A2)                                                                                                      | Built                          | `host.monitor` chooses the monitor; the first-run setup and the Display page show a monitor map.                                                                                                                                                                     |
| 3   | Correct behavior on mixed-DPI monitors (B1.6, B2.6)                                                                                                    | Built, unverified on hardware  | Per-monitor DPI v2 manifest; Host A is rebuilt when the monitor's rectangle or scale changes and puts its rectangle back after a DPI change; cursor effects use the core's normalized positions.                                                                     |
| 4   | 10+ styles and unlimited user-made color themes, including keycap colors (A3, B1.2)                                                                    | Built, with fewer named themes | Six themes (IDEA, Studio, Graphite, Blueprint, Carbon, Glass) and a custom theme (accent, face, ink, glow) with contrast held at 4.5:1; three keycap fonts, four callout sizes, six keyboard layouts and three cursor styles add variety. Six named themes, not ten. |
| 5   | Cursor highlighter with shape, size and color options (A4)                                                                                             | Built                          | Ring, spotlight or dot; size, color and opacity; click ripples shaped per button; optional drag trail; wheel chevrons.                                                                                                                                               |
| 6   | 10+ mechanical keyboard sounds (A5)                                                                                                                    | Built                          | 12 sound packs synthesized in code (no recordings, nothing from Keystro), 4 variations each, volume control. Off by default.                                                                                                                                         |
| 7   | Independent on/off for keystroke display, cursor highlight and sounds (A6)                                                                             | Built                          | Separate switches for callouts, keyboard visual, mouse diagram, cursor effects and sounds; a hotkey for the keyboard visual.                                                                                                                                         |
| 8   | Windows 10 version 1809 (build 17763) or later, x64 (A7, B5.2)                                                                                         | Built, unverified on 1809      | x64 build; every Windows API used exists at build 17763 (DECISIONS item 7). Capture exclusion needs build 19041 and is turned off below it. Tested on `windows-latest` CI only.                                                                                      |
| 9   | Overlay scaling down to very small sizes (B1.5)                                                                                                        | Built                          | Scale from 0.25 to 4 and small sizes for callouts and the keyboard.                                                                                                                                                                                                  |
| 10  | Show macOS and Windows shortcut labels together (B1.4)                                                                                                 | Not built                      | IDEA Keystage is for Windows and SolidWorks, which runs only on Windows; macOS labels would show keys the viewer cannot press.                                                                                                                                       |
| 11  | Overlay stays on top (B1.7)                                                                                                                            | Built, unverified on Windows   | `always_on_top`, re-asserted on every foreground window change without activating; staying above SolidWorks is on the first-run checklist.                                                                                                                           |
| 12  | No interference with dead keys or Alt+Numpad input (B1.8, B1.9)                                                                                        | Built, unverified on hardware  | The hooks only observe and always pass input on; legends use `ToUnicodeEx` with the flag that leaves keyboard state alone, so dead keys are not consumed.                                                                                                            |
| 13  | Cursor click animation and scroll indicator (B2.2, B2.4)                                                                                               | Built                          | Click ripples (a different shape per button) and wheel chevrons, at the cursor and on the mouse diagram.                                                                                                                                                             |
| 14  | Setting to ignore mouse clicks (B2.3)                                                                                                                  | Built                          | Plain left clicks make no callout by default (`plain_left_clicks`); mouse callouts, ripples and the mouse diagram each have their own switch.                                                                                                                        |
| 15  | Cursor highlight hides after a set number of milliseconds (B2.5)                                                                                       | Not built                      | The cursor highlight stays while the pointer is still (it draws no frames then). Not asked for in this version; listed in `docs/ROADMAP.md`.                                                                                                                         |
| 16  | Launch at startup toggle and show or hide the settings window at launch (B4.1, B4.2)                                                                   | Built                          | "Start with Windows" (autostart entry, starts in the tray) and "Open this window at start" on the General page.                                                                                                                                                      |
| 17  | Settings saved to a file, with a warning when the file cannot be used (B4.3)                                                                           | Built                          | `settings.json`, written atomically; a save that fails shows an error with a retry in the settings window; an unreadable file is kept as a backup and a notice says so. There is no separate check for a file locked by another program.                             |
| 18  | Lightweight (B4.6)                                                                                                                                     | Built, measured on Linux only  | Idle overlay page uses about 0.1 percent of one core and draws no frames; the core handles an event in 75 to 157 ns (DECISIONS, Performance). App CPU and memory on Windows are not measured yet.                                                                    |
| 19  | Free tier with a watermark, paid licenses per device, license keys (B6.1 to B6.8)                                                                      | Not built, by design           | IDEA Keystage is free for the IDEA pathway: no watermark, no license, no account, no network.                                                                                                                                                                        |
| 20  | macOS build (B5.1) and Microsoft Store distribution (B5.4)                                                                                             | Not built                      | Windows only; distributed as an unsigned installer and portable exe on GitHub Releases. Code signing is in `docs/ROADMAP.md`.                                                                                                                                        |

Beyond Keystro (not stated on either Keystro page, Part C of the research): OBS Browser Sources with per-source URL settings, global hotkeys, a keyboard visual with live layout legends, a mouse diagram, password-field and excluded-app privacy, SolidWorks captions from Dassault documentation, Session Logs with SRT, Markdown, JSON and YouTube chapter exports, and OBS recording timecodes.
